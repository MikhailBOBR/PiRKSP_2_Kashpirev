## Где лежат материалы

- `Отчёты` — семь отчётов DOCX №2–8. Копия отчёта также находится в папке каждой практики.
- `Архивы` — отдельные ZIP проектов и ZIP со всеми отчётами.
- `practice-*` — исходники, README, запуск, screenshots и run.log.
- `bootcamp` — исходные снимки личного курса; подтверждён общий прогресс 100%.
- `Задания.txt` — исходные условия работ.

В DOCX использовано оформление отчёта Relax1205/PiRKSP_2: A4, Times New Roman 14, полуторный интервал, поля 3/1,5/2/2 см, титульный лист МИРЭА, оглавление и подписи рисунков. ФИО и группа заменены на ваши; преподаватель и дата представления оставлены для заполнения. Исходники и результаты разработаны отдельно от примера.

Java 21 нужна для №2/3. Для №4/5/7/8 нужен работающий Docker Desktop. Готовые классы, зависимости и app.jar включены; Maven необходим только при повторной сборке исходников. Внешние порты: №5 — 8155, №7 — 8177, №8 — 8188. У каждого Compose собственное имя проекта.

## Демонстрации Docker

Из папки №4: `docker compose up --build --abort-on-container-exit --exit-code-from rsocket-demo`.

Из папки №5: `docker compose up -d --build --scale orders=2 --wait`, затем `./demo.ps1`.

Из папки №7 или №8: `docker compose up -d --build --wait`, затем `./demo.ps1`.

На этом ноутбуке проверка выполнялась с отдельным Docker config в рабочем каталоге Codex, потому что обычная конфигурация ранее мешала запуску. Если обычный Docker снова выдаёт ошибку credentials, можно использовать пустой отдельный каталог конфигурации и `docker --config <каталог> compose ...`. Пароли демонстрационных локальных баз и брокера заданы только для учебного запуска.

Скриншоты №6 сняты непосредственно в Remix; остальные скриншоты программ сняты с окна просмотра фактических сохранённых логов; это явно указано в отчётах. Полные исходные логи находятся рядом с кодом. Снимки Bootcamp получены из вашего курса без изменения прогресса.
